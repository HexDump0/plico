Noto fonts for text the standard PDF fonts cannot draw: page numbers,
watermarks, annotations, form values and edits outside Western European
letters. The worker fetches only the ones a job needs and the engine embeds
subsets of them. Unhinted builds from https://github.com/notofonts and the CJK
subsets from https://github.com/notofonts/noto-cjk (`Sans/SubsetOTF`), SIL Open
Font License 1.1 (`OFL.txt`).
